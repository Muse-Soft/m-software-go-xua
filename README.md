# Gỗ Xưa — Xưởng nội thất gỗ thủ công

Gỗ Xưa là xưởng nội thất gỗ thủ công chuyên bàn, ghế, tủ, kệ từ gỗ tự nhiên: chế tác thủ công, hoàn thiện bằng tay, đồ bền, đẹp, dùng lâu.

> Lưu ý: trang web này là bản demo — giá sản phẩm và một số thông tin hiển thị là dữ liệu mẫu, chưa phải báo giá chính thức.

## Cách xem / chạy

Mở file `index.html` bằng trình duyệt, hoặc phục vụ thư mục này bằng bất kỳ máy chủ tĩnh nào, ví dụ:

```bash
python3 -m http.server 8000
```

rồi mở http://localhost:8000

## English summary

Gỗ Xưa is a handcrafted wooden furniture workshop. This single-page site presents the workshop, its collections (dining tables, chairs, cabinets, shelves), the handcrafting process, and a contact form. Prices shown are sample prices only.
